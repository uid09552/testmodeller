MCP access

Connect AI clients such as VS Code to TestModeller through the Model Context Protocol. A key acts as you, in your organisation, with the role you have when you create it. It works only for the MCP endpoint.

Quick setup for VS Code

  1. Create a key below and copy it.
  2. Save this as .vscode/mcp.json in your workspace, or add the server to your user MCP configuration.
  3. Start the testmodeller server in VS Code. It asks for the key once and keeps it in its secret storage, so the file never contains it.
